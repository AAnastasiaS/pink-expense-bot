# Pink Expense Bot

Простой Telegram-бот-кошелек: пишешь `кофе 300`, выбираешь категорию, бот сохраняет запись в SQLite.

## Запуск

1. Создай бота через [@BotFather](https://t.me/BotFather) и получи токен.
2. Установи зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

3. Скопируй `.env.example` в `.env` и вставь туда токен:

```bash
cp .env.example .env
```

4. Запусти бота:

```bash
python bot.py
```

Опционально можно указать путь к базе:

```bash
BOT_TOKEN="твой_токен" DB_PATH="expenses.sqlite3" python bot.py
```

## Как пользоваться

Можно писать прямо в чат:

- `кофе 300` — добавить расход.
- `такси 1 000` — добавить расход с суммой через пробел.
- `+ зарплата 50000` — добавить доход.
- `доход подарок 3000` — еще один способ добавить доход.

Можно пользоваться inline-кнопками под сообщениями:

- `➖ Расход` — бот попросит написать расход.
- `➕ Доход` — бот попросит написать доход.
- `💰 Баланс` — доходы, расходы и текущий итог.
- `📊 Статистика` — статистика за текущий месяц.
- `🗂 Категории` — выбрать категорию и посмотреть расходы по ней.
- `🧾 История` — последние операции.
- `💎 Купить Pro` — купить Pro навсегда за 1 Telegram Star.
- `↩️ Удалить последнюю` — удалить последнюю операцию.

Команды:

- `/start` — открыть меню.
- `/stats` — статистика за месяц.
- `/balance` — баланс.
- `/history` — последние операции.
- `/categories` — расходы по категориям.
- `/pro` — купить Pro навсегда за 1 Telegram Star.

После успешной оплаты Pro-статус сохраняется в SQLite, а кнопка покупки пропадает из меню.
